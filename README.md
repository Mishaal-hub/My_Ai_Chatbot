# AI Chatbot

An AI-powered chatbot designed to provide intelligent, context-aware conversations with a clean and interactive user interface. The project focuses on delivering accurate responses, maintaining conversation flow, and creating a user-friendly chat experience using modern web technologies.

## Features

* 💬 Real-time AI conversations
* 🧠 Context-aware responses
* 🌐 Modern and responsive user interface
* ⚡ Fast backend API integration
* 🔒 Secure API key management using environment variables
* 📱 Mobile-friendly design
* 🎨 Clean and intuitive chat interface

## Getting Started

### Prerequisites

* Node.js
* npm
* OpenAI API Key

### Installation

Clone the repository:

```bash
git clone https://github.com/Mishaal-hub/My_Ai_Chatbot.git
```

Install dependencies:

```bash
cd client
npm install

cd ../server
npm install
```

Create a `.env` file inside the server directory and add your API keys.

Run the backend:

```bash
npm start
```

Run the frontend:

```bash
cd client
npm run dev
```

The application will be available locally after both the frontend and backend are running.
